# 세 외부 회로 계열의 커널 차원과 추가 자원 조사

기존 24개 설정과 겹치지 않는 YZ-CX, Hubregtsen, Kyriienko의 30개 설정을 판정한다. 새 비활성 인증의 수뿐 아니라 전역 Clifford 운반과 Pauli 융합 및 출력 등거리 제거 이후에 실제 작업이 더 줄어드는지 확인한다. 성공 여부를 보고 설정을 제외하지 않는다.

## 고정 범위

기존 102개 조사에서 사용한 소스와 compiler IR을 그대로 사용한다. YZ-CX와 Hubregtsen은 2·4큐비트와 1·2층, Kyriienko는 원 조사와 동일하게 2·4큐비트의 1층만 사용한다. 각 회로에 local XYZ, local Z, Pauli weight at most 2의 단위 대각 metric을 적용한다. 총 10개 소스 회로 구성, 30개 readout 설정이다. 모집단 발생률을 추정하는 표본은 아니다.

계수는 정확한 정수와 반정수만 허용한다. Hubregtsen의 CRZ 분해에서 나타나는 ±1/2는 이진수로도 정확하며 출처 코드의 CRZ와 비교한다. π와 가까운 float를 π 배수로 바꾸지 않는다. 기존 HighDim 상수 문제와 RandomEncoding의 π 계수는 이번 범위에서 제외한다.

## 판정과 예산

각 설정의 기호 항등식에 최대 20초, readout별 제곱 전 최대 200만 항 쌍, 누적 거리식 5만 항을 허용한다. 예산 초과는 항등식 증거 없음으로 기록한다. 형식 미분이 0이면 EXACT_INACTIVE, 원래 공유된 θ와 x에서 구간 미분이 0을 포함하지 않으면 ACTIVE_CERTIFIED, 나머지는 UNDECIDED이다. 형식 비영 계수나 작은 부동소수 미분만으로 ACTIVE를 선언하지 않는다.

증거점은 Python Random seed 20261003으로 고정한다. θ는 2부터 24 사이 정수 /17, 각 입력 좌표는 -15부터 15 사이 정수 /19다. 모든 랭크 행은 같은 θ를 공유한다. 최대 24개 입력 쌍, 50자리 구간 연산을 사용한다. 랭크 상하한이 닫히고 각 기호가 판정되면 조기 종료하되 출처 교차검증을 위해 최소 두 쌍을 평가한다. 시간 초과 시 랭크 상한은 자명한 전체 파라미터 수다. 랭크 하한은 실제 입력점에서 0을 배제하는 소행렬식으로만 채택한다. 재검증은 65자리로 한다.

## 자원 비교와 한계

global-isometry arm은 기존 global Pauli normalizer와 common-isometry 제거를 반복하여 안정화한 회로다. 주 기준선은 여기에 **데이터 의존 각도까지 허용한 observable-commutant 제거**를 더한다. 이 규칙은 운반된 생성원이 모든 readout과 교환하면 그 회전 전체를 제거하며 기존에 알려진 특징 불변 조건이다. 추가 arm은 이 주 기준선 회로에서 이번에 정확히 비활성으로 증명된 좌표를 모두 0으로 고정한 뒤 같은 정규화를 다시 적용한다. 세 arm의 Pauli 회전 작업, 학습 가능 게이트 각도 작업, 잔여 Clifford 게이트, 선형 각도 계수 랭크를 비교한다. 좌표 고정은 실수 파라미터 공간에서의 이상적 커널 동치이며 하드웨어 잡음 동치가 아니다.

게이트별 두 점 parameter shift 비용은 2 × 학습 각도 작업으로 회계 처리한다. 동일 회전의 공유 파라미터 미분은 재사용하지만 서로 다른 회전 occurrence의 shift는 별개다. 단일 입력당 feature-vector 평가 묶음의 수이며 측정 그룹 수와 입력 수를 곱하기 전이다. 고정 shots를 회계할 수 있어도 고정 정확도에 필요한 shots는 측정하지 않는다. 더 강한 상태·측정 최적화가 찾는 제거와 신규 커널 전용 제거를 구분한다. wall time 및 QPU 절감의 실측 실험은 아니다.

구간 연산은 mpmath의 실험적 구현이다. 출처 시뮬레이터, 유한차분, 높은 정밀도 재실행을 교차검증하지만 증명 보조기로 검증된 라이브러리는 아니다. 이전 24개 설정과 이번 설정의 결과를 독립 데이터 문제나 일반적 prevalence로 합산하지 않는다.
