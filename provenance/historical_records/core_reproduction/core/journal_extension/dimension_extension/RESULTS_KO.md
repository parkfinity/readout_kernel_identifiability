# 세 외부 회로 계열 확장 실험 결과

2026년 10월 2일 로컬 실행. YZ-CX·Hubregtsen·Kyriienko의 10개 소스 회로 구성을 3개 readout으로 평가한 30개 설정이다. 기존 24개 파일럿과 겹치지 않으며, 전체 102개 조사를 완료한 것으로 계산하지 않는다.

주요 결과는 두 가지다. **이번 세 계열에서도 강한 기준선 이후 추가 좌표 삭제에 따른 실행 작업 감소는 없었다.** 그러나 Hubregtsen의 한 설정에서 **개별 활성 좌표 4개와 최소 비선형 커널 차원 2가 다르다는 정확한 사례**를 확보했다. 이는 차원 분석의 보강이지 새 QPU 가속 결과는 아니다.

## 새 비선형 사례

Hubregtsen 4큐비트·1층 local Z에서는 마지막 controlled-Z 회전이 모두 측정값과 교환한다. 이 네 파라미터는 강한 기준선이 이미 제거한다. 남은 특징은 정확히 다음과 같다.

`f_q(x) = -sin(theta_q) cos(x_(q mod 2))`, q=0,1,2,3.

따라서 `beta_0 = sin²(theta_0)+sin²(theta_2)`, `beta_1 = sin²(theta_1)+sin²(theta_3)`로 두면, 거리는

`D = beta_0 (cos x_0 - cos x'_0)² + beta_1 (cos x_1 - cos x'_1)²`.

네 좌표는 각각 활성이고, 전역적으로 0인 비자명한 상수 선형 방향은 없다. 그럼에도 커널은 두 비선형 좌표만 본다. 모든 앞쪽 각도를 π/4로 두고 두 입력 쌍을 `((0,0),(π/4,0))`, `((0,0),(0,π/4))`로 잡으면 θ0·θ1 열의 거리 미분 소행렬식이 `17/4 - 3√2 > 0`이다. 상한 2와 하한 2가 일치한다. frozen IR의 특징 지수다항식도 네 식과 정확히 일치했다.

독립 원본 소스 1,000개 입력 쌍에서 닫힌 식과의 최대 커널 오차는 6.67×10⁻¹⁶, 100개 미분점의 최대 오차는 7.50×10⁻¹⁶이다. 수치 검사는 구현 확인용이고, 정확 특징 항등식과 비영 determinant가 증거다.

두 입력을 네 큐비트에 재사용하는 구조와 local Z라는 제한이 중요하다. 이 경우는 가중 고전 cosine-feature 커널로 환원된다. 양자 이점, 일반 비선형 최소화 알고리즘, 기존 최적화 이후 추가 gate/shot 절감으로 표현하지 않는다. β에서 보통의 gradient descent를 실행하면 원래 θ의 유한-step 학습 경로와 같다는 보장도 없다.

## 자원 및 구현 대조

global Pauli 융합·공통 등거리 제거·데이터 의존 observable-commutant 제거를 결합한 기준선 이후, Fourier가 인증한 좌표를 0으로 고정하고 같은 최적화를 적용해도 30개 모두 추가 회전 작업·학습 각도 작업·두 점 shift 평가 묶음 감소가 0이었다. 실제 하드웨어를 실행한 결과가 아니며 고정 정확도 shot 수와 end-to-end 학습 시간은 측정하지 않았다.

원본 소스와의 60개 입력 쌍, 유한차분 504좌표, 자원 arm의 무작위 600개 검사를 모두 통과했다. 최대 특징 오차는 2.67×10⁻¹⁵, interval 미분과 source 유한차분의 차이는 5.32×10⁻⁹, 자원 arm 간 커널 오차는 1.23×10⁻¹⁵, 거리 미분 오차는 1.29×10⁻¹⁴이다. 유한차분은 항등식 수락 기준이 아니다. 단위 테스트는 22개다.

저장된 항등식, 195개 활성 증거, 27개 비영 소행렬식과 자원 arm을 65자리 정밀도로 재검증해 모두 통과했다. 차원 0인 세 설정은 구조 항등식으로 검증한다. 원 실행 manifest 74개 파일의 해시도 모두 일치했다.

## 재현성과 남은 일

첫 실행에서 예외와 타이머가 겹치는 처리 오류를 고쳤고, 저장된 21개 결과를 유지한 채 재개했다. `results/extension_20261001T232302_991451Z/resume.json`에 수정 사유와 기존 파일 해시가 있다. 완성된 설정들의 계산 시간 합은 약 407초이며, 이를 전체 wall time 또는 최적화 가속 수치로 사용하지 않는다.

이 결과의 우선 후속은 Kyriienko의 세 차원 간극이다. 입력·파라미터 점을 추가해 하한이 올라가는지 확인한 다음, 그대로라면 비선형 조합을 찾는 것이 타당하다. 지금 18,900회 cold fit 같은 큰 학습 실험을 추가할 근거는 새로 생기지 않았다.

Linux 서버 재현, 전체 102개 판정, HighDim 상수 원인 추적, 일반 완전 판정과 독립 인간 수학 검토는 아직 완료하지 않았다. 기존 24개와 이번 30개는 조사 범위가 고정된 사례집이며 일반 prevalence 추정이 아니다.

실행 코드는 README에, 기계 판정 원본은 `summary.json`, 구조 결합은 `structural_closure.json`, 비선형 증명은 `nonlinear_hubregtsen.json`, 독립 대조는 `audit_source.json`과 `nonlinear_source_check.json`에 있다. 65자리 증거 재생 결과는 `audit_replay.json`에서 확인한다.
