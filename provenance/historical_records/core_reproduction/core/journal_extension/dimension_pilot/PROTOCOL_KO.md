# 실제 입력 증거와 정확 차원 파일럿

2026-10-02, 결과 계산 전에 고정한 프로토콜.

목적은 구현 가능한 제한 클래스에서 정확 항등식 상한과 실제 입력의 비영 미분 하한을 연결하는 것이다.
이것은 일반적인 완전 판정 엔진도, 기존 102개 설정의 전체 재실행도 아니다.
원고 반영 여부는 결과의 방향이 아니라 증거의 재검증 가능성으로 결정한다. 실패·미결정도 공개한다.

범위는 기존 frozen survey 중 ChebyshevRx와 ParamZFeatureMap, n=2/4, layers=1/2,
local_xyz/local_z/pauli_weight_le_2의 24개 설정이다. 기존 compiler IR을 입력으로 사용한다.
이 두 계열에는 모호한 π 고정각 복원이 필요하지 않다. 모든 숫자 계수는 정확한 정수/유리수로 처리한다.
데이터 식의 정수 배수와 반복 표현을 보존한다. HighDim은 범위 밖이며 임의로 상수를 변경하지 않는다.

방법:

1. Pauli Heisenberg 전개와 정확 유리수 Fourier 계수 합산으로 거리의 기호식을 만든다.
2. θ 방향 미분의 계수가 정확히 상쇄되는 경우만 비활성으로 인증한다.
   형식식이 비영이라는 이유만으로 ACTIVE를 선언하지 않는다.
3. 실제 x∈(−1,1)^2, θ∈R^K에서 interval 상태벡터 및 해석 미분을 독립 계산한다.
   0을 포함하지 않는 미분 구간만 ACTIVE 증거로 인정한다.
4. 같은 θ에서 여러 입력 쌍으로 만든 야코비안의 비영 소행렬식을 interval 연산으로 확인한다.
5. 정확 상수 영공간의 차원에서 얻은 상한과 합치면 r을 확정하고, 다르면 구간으로 보고한다.

파일럿에서 구현하지 않는 경로: 일반 bilinear 완전 cutoff, Schwartz–Zippel 확률적 판정,
임의 source 상수 유리화, 102개 전체 legacy 인증서 재생. 이 경로들은 지원된 것으로 표기하지 않는다.

고정 탐색 규칙: θ는 seed 20261002에서 정수/17로 생성한 하나의 공통 점을 사용한다.
입력은 정수/19의 내부 점을 사용하고 최대 24쌍을 평가한다. interval precision은 50 decimal digits이다.
양의 결과가 나올 때까지 탐색 예산·회로 계열을 늘리지 않는다. 매 설정의 시간과 미결정 사유를 기록한다.
수치 랭크는 소행렬 후보 선택에만 사용하고 최종 하한은 interval 비영성으로 확인한다.

재현성: IR 해시, 입력·θ, 원래 좌표의 미분 구간, rank minor의 행·열·결정값,
정확 영방향과 기호식 해시, 코드·환경·run manifest를 저장한다.
상수 커널 여부를 사전 가정하지 않는다. 특히 ParamZ의 L=1과 L=2를 구분한다.
시간은 인증 비용 진단이며 학습 속도 개선 실험이 아니다. gate/shot 절감은 측정하지 않는다.
