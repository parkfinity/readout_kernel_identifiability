# 커널 차원 파일럿 결과

2026-10-02. 실제 24개 설정을 로컬에서 실행했고, 인증서 재생과 외부 원본 회로 대조까지 통과했다.
162개 기호를 정확 비활성 30개와 실제 입력 활성 132개로 구분했고, 24개 모두 차원 상·하한이 일치했다.
이 결과는 원고 v6 본문과 부록에 통합했다. 기존 v5와 기존 실험 결과는 변경하지 않았다.

## 차원 결과

각 숫자는 일반점에서의 커널 함수 미분 차원이다. 모든 점의 랭크, 게이트 수, shots 수 또는 QPU 비용이 아니다.
8개 회로 설정을 세 readout으로 평가한 것이므로 독립 회로 계열은 두 개다.

## 핵심 해석

대표 ChebyshevRx 2큐비트·2층 local XYZ의 r=4는 앞서 만든 정확 소행렬식과 일치한다.
같은 회로의 local Z에서는 모든 8개 기호가 개별 활성인데도 r=6이다.
θ1과 θ5, θ3과 θ7이 각각 합으로만 나타나므로 개별 활성 판정만으로 매개변수 최소성을 알 수 없다는 실제 사례다.
전체 2큐비트 Pauli readout에서는 r=3이다. readout을 바꾸면 커널이 버리는 방향도 바뀐다.

기존 부분집합의 비활성 18개는 전부 회수했고 12개를 추가했다.
새 항목은 모두 ParamZ/local Z이며, 1층의 상수 Z 특징 6개와 2층 최종 Z 회전의 비활성 6개로 나뉜다.
후자는 데이터 의존 회전이어도 Z 측정과 가환하므로 특징에 영향을 주지 않는다.
이는 알려진 단순 측정 불변성으로도 설명되며, 새로운 내부 metric-transport의 강한 기준선 대비 우위가 아니다.
이 실험으로 새로운 gate/shot 절감이나 학습 가속을 주장하지 않는다.

## 검증과 비용

- 16개 단위 테스트 통과. 이는 이 제한 파일럿의 테스트이며 v2 명세의 모든 일반 기능을 구현했다는 뜻은 아니다.
- 50자리 interval 상태·해석 미분으로 132개 실제 입력 ACTIVE 증거와 22개 비영 minor 생성.
- 65자리 재생에서 같은 증거를 전부 확인. 두 rank-0 설정은 정확 상수 커널 항등식으로 확인.
- 정확 Gaussian-rational 계수 항등식 및 상수 영방향을 별도 기호 엔진으로 확인.
- 외부 고정 sQUlearn source host에서 48개 입력쌍을 재구성해 대조.
- 최대 feature 오차 1.5544×10⁻¹⁵, 거리 오차 3.1975×10⁻¹⁴.
- 원본 회로 기준 324개 좌표 유한차분 오차 최대 2.3739×10⁻⁹. 유한차분은 진단이며 인증의 판정 기준이 아니다.
- 원 실행 82.65초. 이는 로컬 인증 생성 비용이며 반복 측정한 시간 우위가 아니다.

## 이번에 해결하지 않은 것

102개 전체 재실행, 일반 bilinear cutoff 완전성, 모든 상수의 source-level 복원, Linux 서버 재현은 미완료다.
HighDim의 6개 불일치 설정은 원본 라이브러리에서 학습 파라미터 수가 0인 계열이며,
비교된 차이는 컴파일된 고정 회전 계수에 있다. 원본 생성 코드는 RNG가 아닌 고정 siswap 분해를 사용한다.
그러나 구체적으로 어느 플랫폼별 컴파일 내부 선택이 다른 각도를 만들었는지까지 추적한 것은 아니다.
이를 해결했다고 쓰거나 두 수치 IR이 정확히 같다고 간주하지 않는다.

이번 제한 범위는 π 근사 상수 복원을 요구하지 않아 그 문제와 분리해 실행할 수 있었다.
mpmath interval 기능과 구현은 형식 검증된 소프트웨어가 아니며, 인간 독립 검토는 별도로 필요하다.
원고 제출 준비 완료나 PRX Quantum 채택 가능성을 이번 결과만으로 확정하지 않는다.
